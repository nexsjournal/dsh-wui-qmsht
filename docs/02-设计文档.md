# 《清明上河图·众生图鉴》H5 — 设计文档（视觉与交互设计）

> 版本 v1.0（评审稿） | 状态：待确认

## 1. 设计理念

**「展卷 · 点将 · 观天下」**
用户像在看一幅真迹长卷：先展卷（漫游），再点将（选人），后观天下（图谱与世界观）。所有 UI 都是「画上的东西」——按钮是印章，面板是宣纸，边框是绢装裱，动效是墨韵。

### 1.1 三个设计关键词
| 关键词 | 落地 |
|--------|------|
| 真 | 画卷本身是主角，UI 极轻，不遮挡画面（全 UI 元素半透明宣纸底+绢边） |
| 缓 | 动效慢而柔（200~400ms，ease-out 为主），拒绝弹跳与快闪 |
| 古 | 字体、印章、水墨、绢色，全部元素有「宋代」出处感，不混搭明清纹样 |

## 2. 色彩体系

以原画卷绢本色为底，取色自画卷本身（绢底、黛青、赭石、朱砂）：

| 色板 | 色值 | 用途 |
|------|------|------|
| 绢底·宣纸 | `#F4EDE0`（亮）/ `#1B1A17`（夜） | 页面底色、面板底 |
| 墨·玄 | `#2A2620` | 主文字（亮模式） |
| 墨·淡 | `#6B6257` | 次级文字 |
| 黛青 | `#3E5C63` | 强调色、链接、关系线默认色 |
| 赭石 | `#8C5B3F` | 次强调、职业类标签 |
| 朱砂 | `#B03A2E` | 印章、当前 Tab、选中锚点、警示 |
| 描金 | `#C9A96A` | 描边、题字、高光（克制使用） |
| 分组色（图谱/阵营） | 黛青/赭石/墨绿`#5C6B4F`/绛紫`#6E4A5E`/土黄`#B08A3E` | 五大阵营着色（见 05） |

- 默认模式：**夜观长卷**（深底 `#1B1A17` + 微噪点绢纹），画面对比度更好、古风更强；浅色模式（宣纸底）跟随系统。
- 所有叠加在画面上的 UI：`rgba(27,26,23,.72)` 宣纸面板 + 1px 描金边 + 圆角 4px（直角感，拒绝大圆角）。

## 3. 字体

| 用途 | 字体 | 说明 |
|------|------|------|
| 大标题/题字 | 「李旭科毛笔行书」（或「演示夏行楷」，免费可商用） | 卷名、角色名号，`font-display: swap` |
| 正文 | 「思源宋体」(Noto Serif SC) 400/600 | 全部正文、档案文字 |
| 点缀小字 | 思源宋体 600 字距+8% | 职衔、标签 |

- 字体子集化：只保留用到的汉字（约 1500~2500 字），woff2 合计 ≤ 400KB，懒加载；未加载前用系统衬线体兜底。
- 字号体系（移动端基准）：题字 40 / 角色名 28 / 节标题 20 / 正文 15（行高 1.8）/ 标签 12。桌面 ×1.25。

## 4. 版式与关键界面

### 4.0 信息架构
```
H5
├── 开场（展卷动画，2.5s，可跳过）
├── Tab 1 展卷（画卷浏览）
│   ├── 长卷画布（拖拽/缩放）+ 角色锚点 + 地标浮标
│   ├── 迷你导航条（右下/底部，长卷缩略+手柄）
│   └── 角色详情（全屏覆盖层，由锚点开/由图谱开）
│        └── 关系跳转（详情内左右切换，浏览栈）
├── Tab 2 图谱（人物关系连线）
│   ├── 力导向图谱画布（拖拽/缩放/筛选）
│   ├── 「世界」入口 → 世界观长页
│   └── 角色详情（同一组件）
└── 全局：底部 Tab 栏、音乐悬浮按钮、设置（P2）
```

### 4.1 开场
- 黑场 → 两卷轴杆从左右合拢→展开（0.9s）→ 画卷徐徐展平（1.2s，画面从中间向两端 reveal）→ 右上落款「清明上河图·众生图鉴」行书题字淡入 + 朱砂印章「展」盖下（0.3s，带轻微缩放 1.2→1）→ 淡出露出画卷当前视角。
- 任意点击/拖拽跳过；音频策略：开场结束瞬间，若用户已有过交互则开始 BGM，否则显示「点我 展卷听乐」首次引导角标。

### 4.2 Tab 1 展卷（核心界面）
```
┌─────────────────────────────┐
│  清明上河图·众生图鉴   (题字,左上,半透明)  │
│ ┌─────────────────────────┐ │
│ │                         │ │
│ │   长 卷 画 布（全屏画布区）  │ │
│ │   · 角色锚点（虚点/名称）    │ │
│ │   · 地标浮标（虹桥/州桥…）  │ │
│ │                         │ │
│ └─────────────────────────┘ │
│  ◀ 迷你导航条：长卷缩略+手柄 ▶  │
│ ┌─────────┬─────────┐ (♪)  │
│ │   展卷   │   图谱   │ 音乐  │
│ └─────────┴─────────┘      │
└─────────────────────────────┘
```
- 画布区占满屏幕（Tab 栏之上），顶部/底部 UI 均悬浮不占高。
- **角色锚点设计**：
  - 默认态（缩放 <1.5×）：8px 圆点，`rgba(176,58,46,.85)` 朱砂描边空心圆，轻微呼吸（opacity .5~.9，3s）；热区 44px。
  - 显名态（≥1.5× 或开启「人物指引」）：锚点上方浮出竖排小名牌（宣纸底+墨字，竖排古风）。
  - 选中态：外圈水墨晕开动画（radial 扩散 400ms）+ 圆点变实心朱砂 + 名牌加描金边。
  - 悬停（桌面）：锚点放大 1.4× 并显示名牌，光标 pointer。
- **地标浮标**：沿卷 6~8 处，半透明（opacity .5）横向小牌「虹桥·汴河」，点击镜头飞行（600ms ease-in-out）。
- **迷你导航条**：高 36px，长卷极小缩略（1 张 800px 宽 WebP）+ 当前视口框 + 可拖手柄；地标以短刻度标注。移动端默认收起为 8px 细条，点按展开。
- **手势规则**：
  - 单指拖拽=平移；双指捏合=缩放；双击=放大/复位；点击（位移<8px 且 <300ms）=选中锚点。
  - 桌面：左键拖拽平移，滚轮缩放（锚点跟随光标），双击放大；Shift+拖拽=P2。
  - 锚点点击与拖拽冲突消解：锚点热区在拖拽开始即 `pointer-events` 判定，拖拽中不响应点击。

### 4.3 角色详情页（全屏覆盖层）
- **进入动效**：锚点位置生成朱砂印章「点将」落下（150ms）→ 以锚点为中心，宣纸卡片晕开放大铺满全屏（300ms，模糊 8px→0 + scale .96→1）。
- **背景**：原图该角色场景的裁剪矩形（±600px 范围）→ 高斯模糊 12px + 压暗 40% + 绢纹叠加，作为底图；前景为宣纸面板（上滑入场，stagger 120ms）。
- **版面（移动端单列）**：
  1. 头部：角色立绘（圆角 4px，绢边描金）居左 / 名号行书大字 + 职衔朱印 居右；右上「×」（墨笔叉）。
  2. 简介卡：3~5 行人设小传，宋体，首字下沉（朱砂）。
  3. 背景故事：默认显示 1 段 +「展开全文」（折叠动画）。
  4. 人物设定：2 列键值卡（身份/籍贯/营生/性格/擅长/口癖…），键为竖排小字。
  5. 人物关系：横向卡片列表（对方头像+名号+关系标签如「同船」「雇佣」），点按左右滑切换对方详情；顶部关系度指示「与我有缘 N 人」。
  6. 底部固定操作：「在画卷中查看」（定位回锚点）/「在图谱中查看」（切 Tab 并高亮该节点）。
- **桌面（≥1024px）**：左右双栏——左 40% 立绘+背景裁剪图常驻，右 60% 滚动内容区；关系列表改纵向。
- **关系跳转**：详情内容区左滑 24px 露出下一位「下一位」预览条（头像+名号），滑入切换；前进/后退栈（最多 20 层），支持浏览器返回键（history state）。

### 4.4 Tab 2 图谱
- 画布全屏（Tab 栏之上），深色底 + 极淡山水线描底纹（SVG 单色）。
- **节点**：56~72px 圆形墨点（度数加权），内嵌角色头像（原图局部或立绘缩略）+ 底部竖排名号；阵营色描边 2px；选中=朱砂外晕；hover=放大 1.1×+显示简介 tooltip。
- **边**：默认 1px 黛青半透；关系类型：亲眷=双线、交易=单线带「钱」点小标记、同行=虚线、雇佣=实线带箭头、对抗=朱砂线；hover 边→加粗+浮层显示关系说明文案。
- **布局**：力导向 + 四大场景分簇（桥头/市井/城门/郊野，簇内留白更大，簇间 1.6× 间距），簇心有淡色大字水印「桥头·汴河」等。初始运行 120 tick 后**冻结**，节点可单独拖拽（局部松弛 30 tick 后冻结）。
- **筛选**（移动端：顶部横滑胶囊组；桌面：左侧栏）：搜索框（名号/身份模糊）、阵营胶囊、关系类型胶囊；筛选=匹配节点常亮+其余暗化至 15%。
- 顶部右：「世界」印章按钮 → 世界观长页（全屏，滚动长文：时代总纲→汴京四区→五大阵营→名词表，每章题字+分隔墨线）。

### 4.5 底部 Tab 栏
- 高 56px（+安全区），深底半透明毛玻璃（`backdrop-filter: blur(12px)`，唯一例外允许）；两个等宽按钮：图标（竹简/图谱线）+ 文字「展卷」「图谱」；当前 Tab：文字变朱砂 + 下方一枚 6px 朱砂圆点（印章意）+ 图标微亮。
- 切换动效：内容区 250ms 交叉淡化 + 轻微位移（展卷=横向卷动感，图谱=墨点凝聚感）。

### 4.6 音乐悬浮按钮
- 画布区右下角（迷你导航条上方）40px 圆形按钮，古琴剪影图标；播放中=琴弦震动微动效（2px 振幅）+ 音波环；点击开/关；P2 长按呼出音量滑杆。

## 5. 动效规范

| 场景 | 参数 |
|------|------|
| 全局缓动 | `cubic-bezier(.22,.61,.36,1)`（墨韵 out） |
| 面板展开 | 300ms，模糊 8→0 + scale .96→1 + 上移 24→0 |
| 锚点选中晕 | 400ms，径向 0→48px，opacity .6→0 |
| 镜头飞行（地标/定位） | 600ms，位置线性+缩放 ease-out |
| 惯性滑动 | GSAP Inertia 默认（摩擦系数 0.002 调慢，古风「滑绢」感） |
| Tab 切换 | 250ms 交叉淡化 |
| 折叠展开（故事） | 高度动画 280ms |
| 尊重 `prefers-reduced-motion`：全部动效降级为 80ms 淡入淡出 | — |

## 6. 图标与插画资源

- 图标：自绘线性古风图标（竹简、卷轴、印章、琴、墨点），SVG 单色，描边 1.5px，统一 24px 网格。
- 立绘（角色）：AI 生成，**统一模板**——「宋代白描工笔人物立绘，半身/全身，绢本设色，米白底，人物朝左，宋代服饰考据，[角色特征]」；竖构图 1:1.4；WebP ≤150KB。先出 6 张定风格，确认后批量。
- 头像（图谱节点）：立绘 64px 缩略（同一图源裁切），无立绘者用姓氏篆体字替代（自动渲染，零资源）。
- 底纹：宣纸纹理（噪点 PNG 128px 平铺，opacity .05）、山水线描（单色 SVG，图谱底）。

## 7. 文案风格规范

- 人称：角色小传用第三人称半文半白；UI 提示用「你」。
- 禁用：现代网络用语、简体错字、"您"（古风场景避免过度敬语）。
- 示例（船夫·老橹）：
  > 小传：「橹声欸乃，自芦湾渡至汴河已二十余年。人送外号『老橹』，不因其年，因其船上那支老橹，据他自己说，比他年纪还大。」
  > 口癖：「急什么，船到桥头自然直——何况这船，我就是桥头。」

## 8. 无障碍（基线）

- 全部可点元素 ≥44px 热区；锚点名牌文字对比度 ≥4.5:1；
- 键盘可达：Tab 焦点顺序（画布→锚点→Tab 栏→详情），Esc 关闭，←→ 在详情内切换关系人（P1）；
- `aria-label`：锚点=角色名号，按钮=功能名；
- 动效尊重 reduced-motion（见上）。
