# 《清明上河图·众生图鉴》H5 — 技术栈文档

> 版本 v1.0（评审稿） | 状态：待确认

## 1. 技术选型总览

| 层 | 选型 | 版本 | 理由 / 备选 |
|----|------|------|-------------|
| 构建 | **Vite** | 6.x | 秒级启动、原生 ESM、静态资源处理完善。备选：无（React/Vite 亦可，但本项目选 Vue） |
| 框架 | **Vue 3**（Composition API + `<script setup>`） | 3.5.x | 单页内容型 H5，Vue 心智负担低、模板对「古风长列表/档案卡」友好；TS 支持好。备选：React 18（团队熟悉可换，架构不变） |
| 语言 | **TypeScript** | 5.x | 角色/关系数据结构复杂，类型约束必要 |
| 状态 | **Pinia** | 3.x | 角色档案、浏览栈、播放状态、Tab 状态；轻量。备选：裸 reactive store（角色少时可省，但保留 Pinia 便于扩展） |
| 路由 | **不用 vue-router**，自研 3 态导航（`roll` / `graph` / `detail`，用 history state 栈） | — | 只有 3 种页面形态，router 是冗余；自研可精确控制「详情覆盖层 + 关系跳转栈 + 浏览器返回键」 |
| 动画 | **GSAP 3 核心**（tween/timeline/飞行镜头）+ **自研惯性引擎**（已拍板，零成本） | 3.13 | 惯性=速度采样+指数衰减（约 300 行，`core/canvas/inertia.ts`），接口抽象为 `inertia.start(el, opts)`，后期如购买 InertiaPlugin 可无缝替换 |
| 图谱 | **D3-force**（仅用 force 布局算法，渲染自研 SVG） | 7.x | 只需 30 节点力导向，d3-force 足够轻；渲染自研 SVG 便于古风样式与冻结 tick。备选：Cytoscape.js（重，样式定制麻烦）、antv G6（重，但企业级） |
| 音频 | 原生 **HTMLAudioElement** + **WebAudio**（BGM 淡入淡出；四区环境音实时合成，零资产） | — | BGM 走 HTMLAudio；环境音（水声/市声/橹声/风声）由 `core/ambient.ts` 用噪声+滤波+LFO 实时合成，无音频文件、无 Howler |
| 样式 | **原生 CSS**（BEM + CSS 变量主题）+ 少量 SCSS | — | 古风样式大量自定义（竖排、印章、描边纹理），UI 库帮不上忙且体积大；不引 Vant/AntD |
| 工具 | `qrcode` 无；图片处理用 Node 脚本 `sharp`（构建期预处理） | — | 原图切档见 §3 |
| 部署 | 纯静态（`vite build` → `dist/`），任意静态服务器 / 对象存储 CDN | — | 无后端、无 API |

> 依赖体积预估（gzip）：vue 34KB + pinia 2KB + gsap 24KB + d3-force 18KB + 自研代码 ≤ 30KB ≈ **~110KB JS**。性能余量充足。

## 3. 长卷大图性能方案（核心）

原图 10.6MB / 4206×1733，**绝不整图直出**。方案：

### 3.1 三档图（构建期由 `scripts/build-scroll-images.mjs` 用 sharp 生成）
| 档 | 规格 | 用途 | 体积目标 |
|----|------|------|----------|
| 全览档 | 宽 2100px 整图 WebP q82 | 缩放 1×~1.8× 时显示，首屏加载 | ≤ 1.0MB |
| 中档 | 水平切 4 片（每片 2100px 宽），WebP q85 | 缩放 1.8×~2.8×，进入视口才加载（IntersectionObserver 判定，预加载相邻片） | 每片 ≤ 350KB |
| 高清档 | 水平切 8 片（每片 1050px 宽@原始 2103 宽），WebP q88 | 缩放 ≥2.8×，视口内懒加载 | 每片 ≤ 500KB |

### 3.2 运行时策略
- 画面容器 = 一个 `width: 4206 * scaleBase` 的层叠 div（`transform: translate3d + scale`，**只动 transform，永不触发布局**）。
- 三档各为绝对定位 `<img>` 层，`will-change: transform` 只给最上层；切档时两层交叉淡化 150ms，旧档 `display:none` 释放解码内存。
- 切片加载失败/未完成时显示全览档拉伸（视觉可接受），杜绝白屏。
- 移动端内存保护：同时驻留切片 ≤ 5 片，LRU 释放（`img.src=''` + 移除）。
- **降级探测**：`navigator.deviceMemory < 4` 或 `hardwareConcurrency <= 4` → 禁用高清档（最高中档）+ 惯性简化。

### 3.3 其他性能点
- 锚点：≤32 个，纯 DOM（div），坐标 = 归一化 × 容器尺寸，`transform` 跟随；显名名牌懒渲染（仅显名态才建 DOM）。
- 图谱：d3-force 120 tick 后 `simulation.stop()`，拖节点时局部 30 tick 后重冻结；SVG ≤ 60 元素，无动画 tick。
- 立绘：详情打开时 `new Image()` 预载 + `loading=lazy`；头像=立绘同 URL（浏览器缓存）。
- 字体：子集化 woff2，`font-display: swap`，首屏不阻塞（标题字体第二屏再拉）。
- 音乐：BGM 懒加载（首次开启才 `new Audio`）；若做「首 30s 分段」，首段 ≤ 200KB。
- 图片全部 WebP（Safari 15+ 支持）；`<picture>` 兜底 jpg 仅全览档（P2）。
- Lighthouse 预算：JS ≤ 120KB / 首图 ≤ 1.2MB / 字体 ≤ 400KB / LCP ≤ 2.5s（全览档即 LCP 元素，`fetchpriority=high`）。

## 4. 手势与镜头模型

- 统一用 pointer events（PointerEvent 覆盖触摸+鼠标+触控板），双指用 `points Map` 跟踪。
- 镜头状态：`{ x, y, scale }`（x/y 为画布左上角屏幕坐标），边界约束函数 `clamp()` 允许 40px 橡皮筋越界，释放后 300ms 弹回。
- 手势矩阵：
  | 输入 | 单指 | 双指 |
  |------|------|------|
  | 移动 | 平移 | 缩放+平移（中点） |
  | 双击 | 放大/复位 | — |
  | 滚轮 | 缩放（锚点=光标） | — |
  | 拖锚点 | 不区分（阈值 8px 内=点击） | — |
- 惯性：自研引擎——拖拽末段 80ms 速度采样 → 指数衰减积分（每帧 `v *= exp(-k·dt)`，k 调慢呈「滑绢」质感），位移写入 camera 走同一 `applyTo`；低于速度阈值 30px/s 停止；低端机（deviceMemory<4）加大 k 缩短滑行距离。
- 镜头飞行（定位锚点/地标）：`gsap.to(camera, {x,y,scale, duration:.6, ease:"power2.inOut"})`，飞行期间手势可打断（pointerdown 即 kill tween）。

## 5. 图谱实现细节

- 数据：节点 = 角色（含阵营、度数），边 = 关系（type, label, note）。
- 布局：`d3.forceSimulation`，`forceLink`（按关系类型设 distance：亲眷 70 / 交易 110 / 其他 140）+ `forceManyBody(-260)` + `forceX/forceY` 锚向四大场景簇心（strength .08）+ `forceCollide(46)`。
- 渲染：SVG `<g transform>`（节点组）、`<path>`（边，曲线 `q` 二次贝塞尔，弧度按索引错落）。整组用同一 transform 实现画布拖拽/缩放（与长卷同模型，`core/camera.ts` 复用）。
- 冻结策略：120 tick 后 stop；单节点拖拽 → 以该节点为 seed 的 30 tick 局部迭代（`sim.alpha(.3).alphaTarget(.05)` 300ms）→ 再 stop。
- 筛选：CSS class 驱动（`.dim { opacity:.15 }`），无重布局。

## 6. 音乐方案

- 风格：古风纯乐（古琴/箫/琵琶/轻鼓，BPM 60~80，A 小调/羽调式感），时长 2~3 分钟循环。
- **来源（已拍板）**：开发阶段由我检索免费商用曲目（CC0/明确授权，FreePD、ccMixter 古风区等），整理候选清单（≥3 首，含试听链接+授权条款截图）交用户试听选定；授权证据留档 `docs/audio-license/`；最终文件放 `public/media/audio/bgm-1.mp3`。
- 实现：`Audio` 元素 `loop` + WebAudio `GainNode` 淡入淡出（0.8s）；iOS 需 `playsinline` + 首次用户手势内 `resume()`；切 Tab/详情不中断音乐。
- P2 音效：印章「咚」、翻页「沙」，各 ≤ 80KB。

## 7. 角色立绘生成（配合 dsh-imagegen）

- 统一 prompt 模板（中文，喂图生模型）：
  > 「宋代白描工笔人物立绘，[角色特征描述，如：中年船夫，黝黑皮肤，头戴蓑笠，手撑长橹]，绢本设色，淡墨勾线，米白宣纸底，全身/半身像，人物朝向左侧，宋代服饰考据准确，留白构图，无文字水印」
- 尺寸 1024×1408（1:1.375），出图后脚本裁边→WebP 150KB；风格锚定：先出「老橹/酒保/仕女/军汉/货郎/书生」6 张，人工确认后批量。
- 无立绘角色的降级：原图局部放大（`canvas` 裁切 300×420 + 水墨遮罩），零额外资源。

- 代码质量：`eslint` + `prettier` + `vue-tsc`（CI 可后补）；
