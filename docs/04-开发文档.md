# 《清明上河图·众生图鉴》H5 — 开发文档

> 版本 v1.0（评审稿） | 状态：待确认
> 配套阅读：01 需求 / 02 设计 / 03 技术栈 / 05 世界观与角色设定

## 1. 架构总览

```
┌─────────────────────────── App.vue ───────────────────────────┐
│  <Stage>  全屏舞台（管理 3 态导航：roll / graph / detail）        │
│   ├─ RollView      长卷画布（CanvasBoard + 锚点层 + 地标 + 迷你条） │
│   ├─ GraphView     图谱（ForceGraph SVG + 筛选栏 + 世界入口）      │
│   ├─ WorldView     世界观长页                                     │
│   └─ DetailView    角色详情（覆盖层，浏览栈，双 Tab 共用）          │
│  <TabBar>  <MusicButton>  <IntroOverlay(开场)>                    │
└────────────────────────────────────────────────────────────────┘
         ↓ 依赖
   core/（纯 TS：camera / hotspots / graph-layout / nav / audio）
   data/（characters / relations / world —— 内容即数据，单一事实源）
   stores/（pinia：nav、music、filter、anchor-highlight）
```

**原则**
1. `core/` 不依赖 Vue，纯 TS 可单测；Vue 层只做声明式绑定。
2. 内容全部来自 `src/data/*.ts`，改文案/加角色不改 UI 代码；构建期跑数据校验脚本（§4.4）。
3. 画布与图谱共用同一套 camera 模型（`{x,y,scale}` + clamp + 飞行），手势层复用。

## 2. 关键模块设计

### 2.1 长卷画布（core/canvas + core/camera）
- `Camera`：`{x, y, scale}`；`applyTo(el)` 写 `transform: translate3d(x,y,0) scale(s)`；`clamp(bounds, viewport, rubber=40)`；`flyTo(cam, ms)`。
- `PanZoomController`：pointer events 状态机（`idle → panning / pinching`），速度采样（最近 80ms 帧），结束时 `inertia.start(el, {resistance})`（GSAP Inertia）或降级衰减 tween。
- 缩放锚点数学：`newCam = zoomAround(cam, screenPt, k)`，保证「手指/光标下的点不动」。
- 边界：画布逻辑尺寸 `W=4206, H=1733`；`scaleBase` 使初始 `scale` 下画面高度 = 视口高（`scaleBase = vh/H`），`scale ∈ [1, 4]`（相对 scaleBase 的倍数）。

### 2.2 锚点系统（core/hotspots）
- 锚点 DOM 由 Vue 渲染，位置 = `(nx*W, ny*H)` 在画布层内（随 transform 自动缩放），锚点**反向缩放** `scale(1/s)` 保持屏幕尺寸恒定（名牌、点大小不随画面放大而失真；热区下限 44px 屏幕）。
- 显名判定：`scale >= 1.5 || guideOn`；用 IntersectionObserver 对锚点容器做视口剔除（视口外的锚点 `visibility:hidden`，名牌不建 DOM）。
- 点击判定：pointerdown 记录起点，pointerup 时位移 <8px 且 <300ms → `select(characterId)`（写 nav 栈 + 印章动效 + 打开 DetailView）。
- 高亮联动：`stores.anchor-highlight` 供「详情→回到画卷定位」「图谱→高亮」复用（镜头飞行 + 水墨晕）。

### 2.3 三档图层（RollLayers）
- 三个 `<img>` 层叠放（全览 / 中档 4 片拼接 / 高清 8 片拼接），绝对定位同尺寸。
- 档位决策：`scale < 1.8 → 全览`，`1.8~2.8 → 中档`，`≥2.8 → 高清`（带 0.15 滞回防抖）。
- 切片预载：按当前视口在 x 方向覆盖范围，加载 `[i-1, i, i+1]` 片；LRU 驻留 ≤5 片。
- 切档动画：目标层 opacity 0→1（150ms），完成后旧层 `display:none`。

### 2.4 导航（core/nav + stores/nav）
- 状态机：`{ mode: 'roll'|'graph', detail: Stack<CharacterId> (max 20), worldOpen: bool }`。
- 与 `history` 打通：每个 detail push/pop 对应 `history.pushState`，浏览器返回键=关系栈后退；Tab 切换用 query（`?view=graph`）保留分享态。
- 「在画卷中查看」：`closeAllDetails → mode=roll → camera.flyTo(anchor) → highlight`。

### 2.5 图谱（core/graph）
- `layout.ts`：输入 nodes/edges → d3-force 120 tick（同步，约 <50ms@30 节点）→ 输出静态坐标 map（**布局结果存内存即可，无需持久化**；簇心按场景分区固定于画布四象限：桥头偏中上、市井偏右、城门偏右下、郊野偏左）。
- `GraphView.vue`：SVG 渲染；`<g class="viewport">` 挂 camera transform（复用 camera）；边 path 曲线；hover/click 事件委托。
- 节点拖拽：拖中 `pointermove` 实时更新该节点 transform 与相连边；松手后局部 30 tick 松弛（仅影响位移 <200px 的邻居）再冻结。
- 筛选：`stores.filter`（search/阵营/关系类型）→ 计算 `dim` 集合 → 写 class。

### 2.6 详情（DetailView.vue）
- 入参：`characterId` + 来源（anchor 坐标 或 graph 节点，决定入场动效锚点）。
- 背景裁剪：`crop = {x: nx*W-600, y: ny*H-400, w:1200, h:800}` → **运行时**用 canvas 从已加载的中档/全览档 `<img>` 裁切 → `toDataURL('image/webp')` 作背景（零额外请求；注意 canvas taint：同源资源无 CORS 问题，本地/同域静态部署均满足）。
- 关系列表项点击 = `nav.push(对方)`；内容区做 `translateX` 切换（前进左移/后退右移，250ms）。
- 「下一位」预览条：取当前角色关系列表中下一位。

### 2.7 音乐（core/audio + stores/music）
- `AudioEngine`：懒创建 Audio，WebAudio `GainNode`（淡入 0.8s）；状态 `idle/playing/paused`；iOS 首次手势内 `audio.play()` 捕获授权；切页不断曲。
- 首次引导：开场结束后若未授权，右上角浮出「点我·展卷听乐」角标，点一次=授权播放。

## 3. 数据结构（data 契约）

```ts
// src/data/types.ts
type FactionId = 'cangang' | 'shijin' | 'guanhuan' | 'chengmen' | 'jiaoye'; // 漕运渡头/市井百业/官宦士人/城门守备/郊野往来
type SceneId   = 'qiaotou' | 'shisong' | 'chengmen' | 'jiaoye';            // 桥头/市井/城门/郊野（图谱簇心）
type RelationType = 'kinship'|'trade'|'companion'|'hire'|'crowd'|'conflict';
                     // 亲眷/交易/同行/雇佣/围观/对抗

interface Character {
  id: string;                 // 'chuanfu-laolu'
  name: string;               // '老橹'
  title: string;              // '汴河船夫'
  faction: FactionId;
  scene: SceneId;
  pos: { x: number; y: number };        // 归一化 0~1（相对 4206×1733），人工标定
  shortBio: string;            // 小传（3~5 行）
  story: string[];             // 背景故事段落（2~4）
  settings: [string, string][];   // 设定键值：籍贯/营生/性格/擅长/口癖…
  portrait?: string;           // '/media/portraits/xxx.webp'（无则降级）
  crop: { w: number; h: number };      // 背景裁剪范围（相对 pos，px@原图）
}

interface Relation {
  from: string; to: string;
  type: RelationType;
  label: string;     // '同船' '雇佣' '宿怨' …
  note: string;      // 一句话推演依据（图谱 hover + 详情关系项共用）
}

interface Landmark { id: string; name: string; pos: {x:number;y:number}; hint: string }
interface Faction  { id: FactionId; name: string; color: string; desc: string }
```

- 校验脚本 `scripts/check-data.mjs`（`prebuild` 必跑）：
  1. 所有 relation 的 from/to 存在；
  2. 无自环、无重复边；
  3. 每个角色 ≥2 条关系（防孤岛，孤岛角色在图谱上单独提示）;
  4. `pos` 在 [0,1] 内且同点重合 <5px 的角色需人工错开；
  5. 文案长度上限（shortBio ≤ 80 字，story 每段 ≤ 200 字）。

## 5. 风险预案（开发视角）

| 风险 | 触发信号 | 预案 |
|------|----------|------|
| 自研惯性手感不及预期 | M1 真机验收主观评价差 | 调衰减系数 k 与速度阈值；接口已抽象，极端情况购买 InertiaPlugin 替换 |
| 双指+惯性在低端机掉帧 | M1 验收 <50fps | 关闭中档以上切片驻留 3 片；惯性改固定衰减；`contain: strict` 隔离画布 |
| canvas 裁背景在 file:// 下 taint | 本地直接开 index.html 失败 | 文档注明开发用 `vite dev`；裁切失败静默降级为纯宣纸底（try/catch 已兜底） |
| 立绘风格漂移 | 试制 6 张不一致 | 固定 seed 区间 + 同模型同 prompt 模板 + 首张作参考图（图生图模式） |
| 角色坐标与画面人物错位感 | 用户反馈 | 锚点文案加「据画面考据」；坐标标定工具页双人复核 |
